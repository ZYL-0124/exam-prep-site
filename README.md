# 考前刷题 · 学习助手

纯前端、零后端的刷题网站。题目与练习数据全部保存在浏览器 `localStorage`，**不需要服务器、不需要数据库、不需要任何构建步骤**。

## 功能

- **概览**：题库/错题/练习统计 + 续做进度 + 最近练习
- **题库管理**：增删改查、按科目/知识点/题型筛选、五种题型（单选/多选/判断/填空/简答）
- **开始练习**：随机 / 顺序两种模式，顺序模式支持断点续做
- **错题本**：重练、加入/移出错题
- **收藏夹**：收藏题目、单题重练、一键「练习全部收藏」
- **模拟考试**：限时、统一判分、自动交卷
- **成绩统计**：各科目正确率 + 考试趋势图
- **练习记录**：每次练习/考试自动留痕，支持只读逐题回顾
- **背题模式**：翻卡式记忆，先想后揭晓，不判分不计时
- **数据备份**：导出/导入 JSON、下载录入模板、清空

内置 **HCIA AI 题库共 426 题**（按来源文件分为 5 个分类）：
AI Agent 技术与应用 54 / 华为AI技术链与实践 137 / DeepSeek与RAG 60 / 升级考试01 100 / 升级考试02 75。

## 本地运行

直接用浏览器打开 `index.html` 即可；或起一个静态服务：

```bash
python -m http.server 8000
# 然后访问 http://127.0.0.1:8000
```

## 部署

任何静态托管都行（GitHub Pages / Vercel / Netlify / 任意静态服务器）。
把本目录作为**站点根目录**上传即可，所有资源引用都是相对路径。

## 目录结构

```
index.html            入口页面
assets/
  seed.js             初始题库种子（首次打开自动载入；已含 HCIA 426 题）
  store.js            数据层（题库/错题/收藏/练习记录/考试/导入导出）
  app.js              界面与交互逻辑
  styles.css          样式
hcai-bank.json        题库备份文件，可用于「数据备份 → 导入」（可选，可不传）
```

## 备注

- 数据存在各自浏览器本地，换设备/清缓存会丢失，建议定期用「数据备份 → 导出」留底。
- 想换自己题库：进「题库管理」增删，或「数据备份 → 导入」选自己的 JSON。
